## 완료: P0 · P1 수정

### 워치 (df43e58)
- 폰이 운동을 시작해도 진행 중인 워치 운동을 유지 (`WatchLocalWorkoutActivity`)
- 구간 전환·일시정지·종료마다 체크포인트 저장, 앱 재시작 시 기록 복구 (`Recovery/WorkoutCheckpointStore.swift`)
- `WKApplicationDelegate` 추가 → 크래시 후 남은 HealthKit 세션 정리
- 저장 실패해도 요약 화면으로 진행, 결과는 체크포인트 보관 후 다음 실행 재시도
- 폰 종료 신호 유실 시 45초 무수신이면 미러 닫기 버튼 노출
- 기록 상세에서 뒤로가기 복구 (`SummaryView(workout:)`, onDone = nil)

### iOS 운동·미러 (fa3f5ed)
- 권한 요청을 `engine.start` 앞으로 이동, 센서 실패와 무관하게 타이머·전송 시작
- `CoreLocationAdapter` 권한 미결정 콜백에서 continuation 유실되던 경로 수정
- 폰도 체크포인트 저장 + 앱 시작 시 중단 운동 복구, `endStaleActivities()` 연결, Live Activity `staleDate` 갱신
- 미러 present 를 최상단 화면 위에서 수행하고 종료 처리를 멱등으로, 엉뚱한 모달을 닫던 dismiss 제거
- 미러에 항상 동작하는 닫기 버튼, 마지막 수신 시각 기준 연결 판정(워치독 12초/180초)
- 워치 운동 미러 중 폰에서 새 운동 시작 차단

### 빌더·입력 (e439467)
- `DurationFormatter.safeInt` 도입으로 Double→Int 트랩 제거(거리·시간 포맷터 전반)
- 거리 1–100,000m / 횟수 1–10,000 / 목표 0–24h 범위 검증과 안내
- 목표 설정 화면 Done 툴바 + `keyboardLayoutGuide` + 자동 스크롤
- 빌더 드래그가 세그먼트를 삭제하던 문제 수정, 셀 조회를 UUID 기준으로
- 페이스 플래너 목표 0–4시간 선택 + clamp

### 데이터·동기화 (ebe00a7)
- **여자 오픈 월볼 75 → 100회** (24/25~26/27 룰북 확인). `TemplateGoalOverrideStore` 를 구간 목표 델타 저장으로 바꿔 기존 사용자에게도 반영, 구형 전체-템플릿 블롭은 읽을 때 변환
- `StoredTemplate.usesRoxZone` 추가(Optional → 경량 마이그레이션 안전), 레거시 행은 세그먼트로 추론
- 기록 삭제 동기화: `completedWorkoutDeleted` 메시지 + tombstone. 모르는 메시지 종류는 `unrecognized` 로 무시
- 오염 버킷 임시 보정: `tools/pace-data/patch_contaminated_buckets.py` (`--verify` / `--revert` 지원)

### 테스트·가민 (202fdcf)
- 가민 `workout.completed` 숫자 파싱을 NSNumber·Int·Double·String 허용으로 완화
- 요약 테스트 기대값 갱신(커스텀 이름 표시), 미러 UI 테스트 대기시간 연장
